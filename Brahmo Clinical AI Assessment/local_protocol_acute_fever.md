# Sunrise Multi-speciality Clinic — Adult Acute Undifferentiated Fever: Local Treatment Protocol
**Document:** SOP-CLIN-014 · **Version:** 2.1 · **Approved:** 2026-03-10 · **Approver:** Dr. R. Mehta (Medical Director) · **Review due:** 2027-03-10
**Scope:** Adults (≥18y) presenting to Sunrise OPD with acute fever < 7 days, no localizing red flags.

1. Day 0–1: Paracetamol per standard reference dosing; hydration advice; CBC + peripheral smear if fever > 48h; dengue NS1 in season.
2. **Day 2: if fever persists beyond 48 hours without a localizing source, start empirical Azithromycin 500 mg once daily for 3 days.**
3. Day 3–4: review with reports; escalate per findings; admit if warning signs.
4. Documentation: record fever chart and medication reconciliation at each visit.

*Internal clinic document. Not national guidance.*
